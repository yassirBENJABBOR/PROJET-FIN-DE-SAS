#  SAS Progress Console

Application console développée en **JavaScript** pour gérer et suivre la progression des apprenants.

##  OBJECTIF DE PROJET

L'objectif de **SAS Progress Console** est de créer une application permettant de :

-  Gérer les apprenants
-  Enregistrer les résultats par journée
-  Suivre les exercices terminés
-  Suivre les challenges validés
-  Calculer la progression de chaque apprenant
-  Rechercher un apprenant
-  Trier les apprenants
-  Afficher les apprenants selon leur progression
-  Identifier le niveau de chaque apprenant

##  TECHNOLOGIE UTILISER

- JavaScript
- Node.js
- Git
- GitHub
- Terminal / Console


## MENU DE L'APPLICATION 

---------SAS PROGRESS CONSOLE---------

1. Afficher le tableau de bord
2. Afficher la liste des apprenants
3. Ajouter un apprenant
4. Consulter un apprenant par identifiant
5. Ajouter ou modifier le résultat d'une journée
6. Rechercher un apprenant par nom
7. Filtrer les apprenants par niveau
8. Trier les apprenants par progression
